# Node.js_practice

## Notes Application
### Instructions to Run:
- Change directory in terminal to Task 3
- Run each command in terminal:
    - Add a note: node app.js add --title="Buy" --body="Sweets"
    - Remove a note: node app.js remove --title="Buy"   
    - List out all notes: node app.js list  
    - Read a note: node app.js read --title="LIST 1"  
- Adding and removing a note can be seen in notes.json file.
- Listing and reading a note can be seen in the terminal
